# Chitra — Project Documentation

> **Chitra** is a writing-to-card studio for architecture & business plans.
> A piece of writing becomes a typed **card**, cards arrange on an infinite
> **studio canvas** to form flows, and the result exports to PDF, Markdown,
> PNG, SVG, Interactive HTML, DOCX, Notion, or Confluence.
